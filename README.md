# Toniq — ルールベース自動作曲アプリ

ジャンルと雰囲気を選ぶだけで、ループする1曲を自動で作るデスクトップアプリです。
AI（機械学習）は使わず、音楽理論に基づくパターンのデータベース（JSON）と生成ルールで曲を組み立てます。
作った曲は、そのまま細かく編集したり、MIDI・WAV に書き出したりできます。

- 対象：音楽制作をしたことがない人（シンプルモード）、曲のアイデアがほしい作曲経験者（カスタムモード）
- 動作環境：Windows（Electron のデスクトップアプリ）。インターネット接続は不要です。
- 使用技術：Electron + Vite + TypeScript + Tone.js

---

## できること

### メニュー

起動するとメニューが開き、次の5つから選びます。どの画面からも上部の「メニューに戻る」で戻れます。

| メニュー | 内容 |
|---|---|
| シンプルモード | 雰囲気とジャンルを選ぶだけで、すぐに一曲作る |
| カスタムモード | キー・コード進行・ドラム・アレンジ・ミックスまで細かく設定する |
| ミュージックリスト | 保存した曲を聴き返す・管理する |
| 音楽クイズ | 音の高さ・コード・リズム・用語をクイズで学ぶ |
| 設定 | 配色・スキン・音名の表記などを変える |

### シンプルモード

1. **雰囲気**（明るい／暗い／落ち着いた／切ない／激しい）と **ジャンル** を選ぶ
2. **テンポ**を「ゆっくり／普通／速い」から選ぶ（「タップで調整」でボタンを叩いた速さにもできる。「クリックで試聴」で速さをクリック音で確かめられる）
3. メロディを「自動生成」にするか「自分で入力（ピアノロール）」にするかを選ぶ
4. **「✦ 生成する」**を押すと、コード進行・ドラム・メロディが決まり、曲ができる

生成後にできること：

- 再生／停止（パートがコード進行1周ごとに増えていく構成で鳴る）
- メロディ・コード・ドラムを1つずつ**差し替え**（再抽選）
- **MIDI・WAV で書き出し**
- 「カスタムモードで編集する」で、設定を引き継いで細かく編集

ジャンルを選ぶと一言の説明が出て、「▷ ○○ のサンプルを聴く」でそのジャンルの雰囲気を試聴できます。

### カスタムモード

設定は変えたその場で反映されます（再生中なら再生し直します）。3つのタブがあります。

**設定タブ**

| 項目 | 内容 |
|---|---|
| 基本設定 | BPM（ノブ・タップ・クリック音で試聴）、小節数（曲全体の長さ）、ジャンル、メロディの音色 |
| スケール・キー | ルート音（C〜B）、スケール、スケールロック（コード進行を同じスケールに絞る） |
| コード進行 | カテゴリ（雰囲気）、進行（◀▶で聴き比べ）、試聴、リズム（全音符〜8分）、コードの音色 |
| ドラム | カテゴリ、パターン（◀▶）、試聴 |
| FX / SE | ループの継ぎ目の効果音の種類（ライザー・インパクトなど）と試聴 |
| パッド／アルペジオ／シグネチャー | 追加パートの ON/OFF（シグネチャーはジャンルの特徴を出すパート） |
| ミキサー | パートごとの ON/OFF・音量フェーダー・レベルメーター |
| 書き出し | MIDI・WAV |

**アレンジャータブ**

- パートごとに、どの小節で鳴らすかをブロックで配置する（クリックで置く、ドラッグで移動・長さ変更、右クリック／×／Delete で削除）
- ドラムと FX のブロックは、ブロックごとにパターン・種類を変えられる
- 小節番号の目盛りをクリックすると、そこから再生できる
- 「標準に戻す」でジャンルの標準アレンジに戻す
- コード・ドラム・メロディの差し替え、ミキサー、書き出しもここから使える

**ピアノロールタブ**（シンプルモードにもあります）

- メロディを手で入力・編集する（クリックで置く、ドラッグで移動・長さ変更、右クリック／Delete で削除）
- パソコンのキーボード（A〜K、黒鍵は W E T Y U）で入力、Z / X でオクターブ切り替え
- 音符の長さ、スケールロック（スケール外の音を置けなくする）、自動生成、クリア

### 両モード共通

- **元に戻す／やり直す**（ボタン、Ctrl+Z / Ctrl+Shift+Z・Ctrl+Y）
- **♪ 保存**：今の曲をミュージックリストに保存（リストから開いた曲は上書き保存）
- **＋ 新規作成**：設定をリセットして新しい曲を作る
- 用語のツールチップ：点線の下線がある言葉にカーソルを乗せると、初心者向けの短い説明が出る

### ミュージックリスト

- 保存した曲の再生・停止（再生位置のバー付き）
- 曲名で検索、ジャンルで絞り込み、お気に入りだけ表示、並び替え（新しい順／古い順／名前順）
- 曲ごとのメニュー：保存したモードで開く、名前を変更、ファイルに書き出す、削除
- 曲ファイル（`.toniq.json`）の読み込み・すべて書き出し（バックアップや別の PC への持ち運び用）

曲はアプリ内（localStorage）に保存されます。

### 音楽クイズ

初心者向けのクイズです。4つのカテゴリの中に、やさしい順に出題モードが並んでいます。

| カテゴリ | 出題の例 |
|---|---|
| 音の高さ | ドレミと CDE、鍵盤の位置当て、高い？低い？、音程聴音、度数・半音数、音程（度数）、2音間の音程 |
| コード・スケール | メジャー/マイナー判定、コード構成音、コード聴音、コードの度数構成、コード進行聴音、スケール構成音、スケールの度数構成、平行調 |
| リズム・音響 | 拍子判定、周波数帯域 |
| 用語 | Toniq の用語、シンセのパラメータ |

選択肢か鍵盤で答え、回答後に一言の解説が出ます。モードごとに出題範囲などの設定ができ、正解数と連続正解数を表示します。

### 設定

- 配色（ライト／ダーク／OS に合わせる）
- カスタムモードのスキン（デフォルト／フラット／スタジオ／ポップ）
- 音名の表記（CDE／ドレミ）
- ループ再生（曲の最後まで来たら先頭に戻る）
- ドラムの音源（シンセ／ワンショット音源。テスト中）
- 用語のツールチップの ON/OFF

設定はこのパソコンに保存され、曲には保存されません。

## 曲の作られ方（概要）

| パート | 作り方 |
|---|---|
| コード | コード進行DB（`chord_progressions.json`）から選ぶ。ディグリー（Im・bVI など）で持ち、キーに合わせて実音に変換する |
| ドラム | ドラムパターンDB（`drum_patterns.json`、16ステップ）から選ぶ |
| ベース | ジャンルごとのパターン（`bass_params.json`）でコードのルートを鳴らす |
| アルペジオ・パッド | コード進行から自動で作る |
| メロディ | ペンタトニックを中心に、ジャンルごとのリズムとフレーズ形式（`melody_params.json`）で自動生成する |
| シグネチャー | ジャンルの特徴を出す追加パート（EDM のコードスタブ、ローファイのレコードノイズなど） |
| FX / SE | ループの継ぎ目の効果音 |

シンプルモードでは「ジャンル×雰囲気」の表（`easy_mode_table.json`）から、コード進行とドラムを選びます。
ジャンルごとに、コード進行1周ごとにパートが増えていく標準のアレンジがあります。

**ジャンル**：EDM／8bit／ローファイ／ゲームBGM／テクノ／ハウス／トランス／アンビエント
**雰囲気**：明るい／暗い／落ち着いた／切ない／激しい

## 制限

- 拍子は 4/4、1小節16ステップ固定（3拍子・3連符・スウィングは不可）
- MIDI 書き出しはコード進行1周分のメロディ・コード・ベース（ルート音）・アルペジオだけ（アレンジ・ドラム・パッドは含まない）
- MP3 書き出しとキー・スケールの試聴は未対応

## 開発

```bash
npm install             # 依存パッケージのインストール
npm run dev             # ブラウザで開発（Vite, http://localhost:5173）
npm run electron:dev    # Electron で開発起動
npm run build           # 型チェック（tsc）＋ビルド
npm run electron:build  # Windows インストーラを作成（release/）
```

テスト・Lint は未導入です。変更後は `npx tsc --noEmit` で型チェックします。

### フォルダ構成

```
electron/      Electron のメインプロセス
index.html     画面（メニュー／シンプル／カスタム／ミュージックリスト／クイズ／設定）
src/ui/        画面ごとの処理
src/engine/    状態管理（AppState）・生成・再生・書き出し
src/quiz/      音楽クイズの出題と音
src/data/      パターンDB（JSON）とディグリーの変換
public/samples ドラムのワンショット音源
docs/          基本設計書と設計図（PlantUML）
```

開発のルール（状態管理・ジャンルの追加手順など）は [CLAUDE.md](CLAUDE.md) にまとめています。
