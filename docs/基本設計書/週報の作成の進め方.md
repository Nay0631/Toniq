# 週報の作成の進め方

Claude Code で、ガントチャートの進捗を書き込み、担当者ごとの週報を作るときの手順です。Claude Code が行う中身は `.claude/skills/weekly-report/SKILL.md` にあります。ガントチャートの行を足す・直す作業は [基本設計書の更新の進め方.md](基本設計書の更新の進め方.md) の「3. ガントチャートの更新」で行います。

## いつ行うか

| 作業 | タイミング |
|---|---|
| 週報の作成（先週の進捗の書き込みを含む） | 週の初め（月曜か火曜）に週1回 |

- 同じ週に「ガントチャートの更新」（`/update-gantt`）も行うときは、**ガントチャートの更新を先に**行い、コミットしてから週報を作ります（理由は下の「注意」）。
- ガントチャートを書き換える作業（週報の作成・ガントチャートの更新）は、**1人ずつ順番に**行います。2人が別々に行うと、同じ番号の別のファイルができてしまいます。

## 手順とプロンプト

プロンプトは日本語の文で頼めます。右の列のコマンド（`/` で始まるもの）を入力しても、同じ作業になります。

### 週報の作成

**手順**

1. `main` の最新を取り込み、Excel でガントチャートを閉じてから、Claude Code に下のプロンプトを送る。
2. Claude Code が今日の日付を確かめ、先週・今週（どちらも月曜〜日曜）を決める（例：11/24（火）に頼むと、先週は 11/16〜11/22、今週は 11/23〜11/29）。
3. 先週にかかるタスクのうち、**先週の日曜までに終わる予定で、進捗が 100% でない行**の進捗が 100% になる。終わりが今週以降のタスク（先週から続いているもの）は変わらない。先週より前に終わる予定なのに 100% でない行は自動では変わらず、最後に知らされる。
4. 進捗を書き込んだときは、ファイル名の最後の番号が1つ上がる（`ガントチャート(アプリオリ)1119.xlsx` → `…1120.xlsx`）。書き込む行がなかったときは上がらない。
5. 担当者（根井・西薗・小手川）ごとに、「先週の主な作業内容」「先週の所感・問題点」「今週の主な作業内容予定」がそれぞれ要点を選んで20行程度にまとめて示される（すべてのタスクを並べるのではなく、似たものはまとめ、細かいものは省く）。同じ内容が `output/weekly/週報_<今週の月曜>.md` に保存される（Git には入らない）。
6. 進捗を 100% にした行の一覧を見て、実際には終わっていないタスクがあれば、Excel でその行の進捗を戻す。週報の中身も、実際と違う所を直してから使う。
7. 新しい名前のガントチャートを Excel で開いて、進捗の列と書式を確認する。
8. 問題がなければコミットする（前の名前のファイルの削除と、新しい名前のファイルの追加の両方をコミットする）。

**プロンプト**

| 場合 | 頼み方 | 同じ意味のコマンド |
|---|---|---|
| 普段（今日を基準にする） | `週報を作って` | `/weekly-report` |
| 基準の日を決めて作る | `2026-11-30 を基準に週報を作って` | `/weekly-report 2026-11-30` |

## 注意

- 週報は**ガントチャートだけ**をもとに作ります。Git のコミットや実際の作業の記録は見ないので、ガントチャートにない作業は週報に出ません。予定と違う作業をしたときは、週報を手で直すか、先にガントチャートを直します。
- 進捗は「予定の終わりを過ぎたら 100%」として書き込みます。実際に終わったかどうかは確かめないので、6 の確認を必ず行います。
- 2・4・7章（クラス図・ロバストネス図・シーケンス図）と 8・9章の開始・終了は、上から順に並ぶように割り当て直した日付で、実際の作業日とは限りません（2026-11-24）。
- ガントチャートの更新（`/update-gantt`）は、日付が上から順に並ぶように開始・終了を割り当て直すことがあります。進捗は行についたまま動かないので、週報で進捗を書き込んだあとに日付が割り当て直されると、「まだ先の予定なのに 100%」「終わった予定なのに 0%」の行ができることがあります。同じ週に両方を行うときは、ガントチャートの更新を先に行います。
- ガントチャート（xlsx）は Git で中身をまとめる（マージする）ことができません。ほかの人がガントチャートを書き換えたブランチがあるときは、それが `main` に入ってから作業します。
- シート「2027」は触りません（「2026」を参照しているだけです）。
- コミット・push は自分で行います（Claude Code は行いません）。
