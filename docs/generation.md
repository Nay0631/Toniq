# 自動生成とパート（メロディ・コード進行・各パート・自動チェック）

詳しい仕様。CLAUDE.md の「詳しい仕様」から参照される（要点・決まりごとは CLAUDE.md）。

## メロディ

- メロディ生成の規則（`MelodyGenerator.ts`。`generateMelody(progression, key, genre, { section, prevNote, nextNote, pitchClasses })`）：
  - コード構成音を見て音を選ばない（2026-11-17 に変更。以前は小節の頭・3拍目の頭をコード構成音にし、掛留も入れていた）。音はスケールの役割（`SCALE_TONES`）だけで決める。
  - 基本の5音（`core`）：メジャー系（major・mixolydian）はスケールの 1・2・3・5・6 番目（メジャーペンタトニックの形）、マイナー系（minor = ナチュラルマイナー・harmonic_minor・melodic_minor・dorian・phrygian）は 1・3・4・5・7 番目（マイナーペンタトニックの形）。まずこの5音だけでメロディを作る。
  - 外す：そのあと1小節に数回（`accentsPerBar`：小節の音が2〜3個なら1回、4〜7個なら2回、8個以上なら3回）、残りの2音（`accent`。メジャー系は 4・7 番目、マイナー系は 2・6 番目）に置き換える。今の音から2半音以内（なければ3半音以内）の音にし、次の音は進む先（`accent` の値）へ順次進行させる（同じ小節の中なら次の音を直す）。小節の最初の音（ほかに置ける所がないときを除く）・フレーズの終わりの音・続けての外しは避け、前後の音から `JUMP_LIMIT` を超えて跳ばない。同じ文字（モチーフ）の小節はなるべく同じ位置で外す。音が1つだけの小節・終止の小節では外せないことがある。
  - 同じ音の連続を許す（`MAX_REPEAT` = 3 回まで、重み `REPEAT_WEIGHT`）。
  - 使う音の数の上限（`melody_params.json` の `pitchLimit`。テクノ = 2）：主音を含むその数の音名だけで作り、ミニマルにする（外す・跳躍の直しはしない）。もう1音は基本の5音からランダム。主音を音域の真ん中に置き、もう1音は Aメロでは主音の下、サビでは上に置いてサビを高くする。サビは `pitchClasses`（Aメロで使った音名。`SongForm.ts` の `chorusMelodyAfter` が渡す）と同じ音名で作る。
  - 輪郭：フレーズ形式1回分を1つの形（`CONTOURS`：山型・上昇・下降・波）で動き、各音はその位置で狙う高さに近いほど選ばれやすい。音域のうち Aメロは低め〜中、サビ（`section: "B"`）は中〜高（`SECTION_SHAPE`。音域の狭いジャンルは `melody_params.json` の `verseBand` / `chorusBand` で上書きする。ローファイ・アンビエントはサビが盛り上がりにくかったので Aメロ [0, 0.5]・サビ [0.5, 1]）。`prevNote` は直前に鳴る音で、最初の音をその近くに置く。`nextNote` はこのメロディのあとに鳴る別のメロディの最初の音（サビのあとの Aメロの頭）で、最後の音をそこからも離しすぎない。
  - 次の音の選び方（`pickNextNote`）：小節の最初の音は、直前の音から大きく跳ばない範囲で輪郭の高さに近い音。それ以外は輪郭の高さに近い音ほど選ばれやすく、直前の音に近い音（順次進行）にも重みを付ける（`preferStepwise` のジャンルは強く、そうでないジャンルも弱く）。`maxLeap` を超える跳躍はしない。
  - 終止：進行の最後の音は主音（なければ5度・3度）にし、短ければ少し伸ばす。直前の音から `JUMP_LIMIT` を超えて跳ばない候補を優先し、そのうえでループの頭の音（と `nextNote`）からも離れすぎない高さを選ぶ。前半の最後の小節の最後の音は主音を避けて5度・2度などで止める（問いかけと答え）。
  - リズムは `melody_params.json` の `rhythmPatterns`（16ステップ表記。`x` = 発音、`-` = 伸ばす、`.` = 休符。ジャンルごとに12〜13個）から小節ごとに選ぶ。サビ（`section: "B"`）は `chorusRhythmPatterns`（拍の頭から始まり長く伸ばす音の多い、Aメロと違う感じのリズム。なければ `rhythmPatterns`）から選ぶ。リズムを足したら `npm run quality` で書式（自動チェックの「メロディのリズムDB」）と合格率を確かめる。
  - `phraseForms`（例 `"AAAB"`。1文字 = 1小節）で同じ文字の小節は同じモチーフを使う。小文字（例 `"AABa"` の `a`）は大文字と同じモチーフで、最後の1〜2音を必ず選び直す（A'）。基本の5音の上でずらして繰り返す（ゼクエンツ。直前の音に近く、輪郭の高さに合うもの。音域に収まらない・跳躍が大きすぎるなら同じリズムで音を選び直す。`pitchLimit` のジャンルはそのまま繰り返す）。くり返しは確率（`DEFAULT_VARIATION`）で最後の1〜2音だけ選び直す（A → A'）。形式より長い進行は形式を繰り返す。
  - 跳躍の直し：最後に、続けて鳴る音（間の休符が1拍未満）の跳躍が `JUMP_LIMIT`（9 半音。自動チェックの基準と同じ）を超える所を、小節の前側か後ろ側をまとめてオクターブ動かして直す（`smoothLeaps`。超えた分の合計が減る動かし方を、小さい範囲から選ぶ。音域の外には出さない）。まとめて動かすので小節の中の動き（モチーフ・外した音の進み方）は変わらない。ループの継ぎ目（最後の音 → 最初の音）と、`prevNote` / `nextNote` との継ぎ目も数える。直しきれないのはサビの終わり → Aメロの頭のように両側の兼ね合いがある所だけ（2026-11-13 の計測で跳躍の合格率は 46% → 88%）。
  - 音価は `4n` などのほか付点（`8n.` など）や `0:拍:16分` 表記も出る。MIDI書き出しは `MidiExporter.ts` の `durationToBeats` で変換する。

## コード進行の選び方

- シンプルモードの生成（`resolveSimpleMode`）は、`easy_mode_table.json` の候補に加え、`chord_progressions.json` でジャンル・雰囲気のタグが両方合う進行からも選ぶ（表の候補は `TABLE_WEIGHT` = 2 倍選ばれやすい）。以前は表の 2〜5件からしか選ばず、何曲作っても同じ進行に当たりやすかった（1組あたりの進行の種類が平均 3.0 → 11.2）。差し替え（`rerollChord`）も同じ候補から選ぶ。ドラムは今までどおり表の候補から選ぶ。
- スケール：major（メジャー）・minor（ナチュラルマイナー。表示名は以前「マイナー」）・harmonic_minor（ハーモニックマイナー）・melodic_minor（メロディックマイナー）・dorian・phrygian・mixolydian（ミクソリディアン）・lydian（リディアン）・major_pentatonic（メジャーペンタトニック。5音）・whole_tone（全音音階。6音）。5音・6音のスケールはメロディで外す音がない（`SCALE_TONES` の `accent` が空）。メジャーペンタトニックのコードの根音はメジャーと同じで、ペンタトニックの音でできた sus2・sus4・add9・min7 を使う。全音音階のコードは aug・aug7。
- コードの種類（`CHORD_INTERVALS`）：major・minor・dim・aug・maj7・min7・dom7 に、maj9・min9・dom9（9th）・add9・sus2・sus4・aug7 を足した（2026-11-17）。1オクターブを超える音（9th）は `resolveChord` が上のオクターブで返し、ボイシング（`voicingCandidates`）は転回したあと低い順に並べ直す。
- ジャンルに合うスケール（`genre_scales.json`）：EDM = ナチュラルマイナー・ハーモニックマイナー、8bit = メジャー・ナチュラルマイナー・ハーモニックマイナー、ローファイ = ドリアン・ナチュラルマイナー・メジャー（メジャーの進行は 7th・9th を足したものだけをローファイに付ける）、ゲームBGM = メジャー・マイナー・ミクソリディアン・ドリアン・リディアン、テクノ = フリジアン・ナチュラルマイナー（メロディは2音。`pitchLimit`）、ハウス = ドリアン・ミクソリディアン、トランス = ハーモニックマイナー・ナチュラルマイナー、アンビエント = リディアン・メジャーペンタトニック・全音音階。
  - シンプルモードの生成・差し替え（`resolveSimpleMode` / `rerollChord`）は、候補（表＋タグ）をこのスケールの進行に絞る（`preferGenreScales`。原則なので、1つも残らなければ絞らない）。サビは Aメロと同じスケールから選ぶので、そのままジャンルのスケールになる。
  - カスタムモードは自由に選べる。スケールの選択肢のうち、ジャンルに合うものに「（おすすめ）」を付ける（`CustomRender.ts`）。
  - どのジャンル×雰囲気も、合うスケールの候補が3件以上あるようにする（`tests/GenreScales.test.ts`）。2026-11-17 にハウス（chord_081・082 とタグ）・ローファイ（chord_083・084）・アンビエント（chord_085〜093）の進行を足し、テクノの明るい・落ち着いたにナチュラルマイナーの進行のタグを足した。
  - ジャンルを足すときは `genre_scales.json` にも足す。カスタムモードのスケールの選択肢は、コード進行DBにあるスケールを `SCALE_LABELS`（`format.ts`）の順に並べる（`CustomState.ts` の `SCALES`）。2026-11-17 にハーモニックマイナー（chord_075・076）・メロディックマイナー（chord_077・078）・ミクソリディアン（chord_079・080）の進行を2つずつ足した（サビの相方がいるよう同じ長さで2つ）。
- 進行を足すときは、どのジャンル×雰囲気も候補（表＋タグ）が5件以上になるようにする（2026-11-13 に chord_062〜074 を足して全組5件以上）。サビの相方（同じ長さ・スケール）があるか・実音にできるかは `npm run quality` の「コード進行DB」で確かめる。

## ベース・アルペジオ

- ベース（`BassPlayer.ts`）はジャンルごとに `bass_params.json` のパターンで鳴らす。音は lidless（ジャンルの標準は `BASS_STANDARD`）で、lidless の準備ができていないときは `bass_params.json` の `synth` の Tone.js の音色。パターンは16ステップ表記（`R` = ルート、`F` = 5度、`O` = 1オクターブ上、`-` = 伸ばす、`.` = 休符）。`patterns` を小節ごとに順に使い、コード進行1周の最後の小節は `fill`（曲全体の並びでは `section_bars` ごと）。5度はコードの構成音から取る。音色はジャンルで決まり、Synth を作り直したとき（再生開始時）に反映される。
- ベースとキック：ベースの強さは `bassVelocity(bar, step)`（`BassPlayer.ts`）で、キック（`kickAt()`。アレンジ・ブロックのパターン・フィルも反映）と同時の音を強く、それ以外は拍の頭 > 裏の順に弱くする。MIDI書き出しも同じ。
- アルペジオ（`ArpPlayer.ts`）はジャンルごとに `arp_params.json` で鳴らす。`instrument`（`pluck` / `square` / `keys` / `bell` / `blip`。定義は `ArpPlayer.ts` の `INSTRUMENTS`）、`step`（`16n` / `8n` / `4n`）、`pattern`（`up` / `down` / `updown` / `pedal` = 一番下の音と交互）、`octaves`（2 なら1オクターブ上を重ねる。ボイシングは `VOICING_RANGES.arpWide`）、`gate`（刻みに対する音の長さ）、`cutoff`、`delay`。パターンはコードが変わるたびに頭から。音の並びは `arpNotes()` で作り、MIDI書き出しも同じものを使う。音色・ローパス・ディレイは再生開始時に反映される。
- サブベース（`AppState.bassSub`。`null` = ジャンルの標準で `bass_params.json` の `sub`。EDM・トランス・テクノが ON。`SONG_FIELDS` に含む）：ベースの各音を E1〜D#2 にたたんだ高さ（`subMidi`。オクターブ上の `O` もルートになる）で、lidless の「サブベース」（なければ Tone.js のサイン）を −6dB（`SUB_LEVEL_DB`）で重ね、本体のベースは 90Hz から下を削る（`BassPlayer.ts`）。カスタムモードの設定タブの「追加パート」欄で選ぶ。音色と同じく再生開始時に反映される（再生中に変えたら再生し直す）。MIDI書き出しはしない。ジャンルを足すときは `bass_params.json` に `sub` も入れる。

## 追加パート（カウンターメロディ・パーカッション・シグネチャー・FX / SE）

- カウンターメロディ（`CounterPlayer.ts`）はメロディに寄り添うもう1本の旋律。曲全体の並び（`songProgression()` / `songMelody()`）から `counterNotes()` で毎回同じ形に作る（AppState には持たない。メロディを編集すれば追従する。`reloadLayer("melody")` はカウンターメロディも読み込み直す）。
  - サビ（コードの `section` が B）はハモり：メロディの各音と同じ位置・長さで、3度下（なければ6度下・4度下）のスケール音。強拍（1・3拍目）はコード構成音を強く好む。G3 より下になる音は休む。
  - Aメロ（それ以外。試聴・サンプルも）は合いの手（オブリガート）：次の発音まで半小節以上空く所に、発音の1拍あとから8分音符2〜4音のフレーズを G4〜C6 のペンタトニックで入れる（最初と最後はコード構成音、鳴っているメロディと短2度・長7度でぶつけない、次のメロディの発音の前に終わる、サビに食い込まない）。1小節に1つまでで、続く小節には入れない。メロディが細かいジャンル（8bit・テクノ）では Aメロではほとんど鳴らないので、標準アレンジでは主にサビ（とメロディの間が空くジャンルの Aメロ）に置く。
  - 音は lidless（`growSounds.counter`。ジャンルの標準は `Grow.ts` の `COUNTER_STANDARD`）。MIDI書き出しも同じ音。ジャンルを足すときは `COUNTER_STANDARD` にも足す（なければローファイの定義）。
- パーカッション（`PercPlayer.ts`）はドラムに重ねる小さな打楽器（`shaker` / `tambourine` / `conga_high` / `conga_low` / `ride`）。ジャンルごとに Aメロ・サビ（`sectionAt(bar)`）の16ステップのパターン（`PERC_PATTERNS`。`X` = 強く、`x` = 普通、`o` = 弱く、`.` = 休み。ないジャンルはローファイ）で鳴らし、サビのほうをにぎやかにする。音はドラムの音源に合わせ、`"grow"` なら lidless の「パーカッション …」のプリセット（`SynthFactory.ts` の `GROW_PERC`）、ワンショット音源（`"sample"`）ならドラムと同じフォルダの `<トラック名>.wav`（`DrumSamples.ts`。ジャンルのフォルダ → `default`。ないトラックは lidless）、シンセならシンセ（lidless を鳴らせないときもシンセ）。ドラムのバスは通さず、150Hz から下を削ってジャンルのキットの高域カット（11kHz より下げない `PERC_LOWPASS_MIN`）だけ通し、全体を `PERC_TRIM_DB`（−6dB）下げる（`createPercKit`）。エンディングの小節では鳴らさず、揺らぎはドラムの揺らぎ（`drumHumanize`）に合わせる。サイドチェインでは沈めない。MIDI書き出しはチャンネル10の別トラック（GM の音の番号。シェイカーは Maracas）。ジャンルを足すときは `PERC_PATTERNS` にも足す。
- シグネチャー（`SignaturePlayer.ts`）はジャンルの特徴を出す追加パート。EDM = オフビートのコードスタブ、テクノ = アシッド（16ステップ表記 R/O/F、大文字はアクセント）、8bit = 32分音符の高速アルペジオ、ローファイ = レコードノイズ（ヒス＋ランダムなプチプチ音）、ゲームBGM = ブラス、ハウス = シンコペーションのピアノスタブ、トランス = スーパーソウのコードを16分で刻むトランスゲート、アンビエント = うねる風のノイズ。ジャンルごとに `label` / `create`（Synth とエフェクト）/ `events`（コードごとの発音）を定義する。音色はほかのパートと同じく再生開始時に反映される。MIDI書き出しは未対応。
- FX / SE（`FxPlayer.ts`）はループの継ぎ目を演出する効果音。種類は `AppState.fxType`（`SONG_FIELDS` に含む）で、`"auto"` はジャンルの標準（`GENRE_FX`）。カスタムモードのドラム欄の下の「FX / SE」で選び、「▷ 試聴」はループの終わりの盛り上げから次のループの頭の1小節まで鳴らす（`Playback.preview("fx")`）。
  - アレンジャーの FX はセクションごとに種類を持てる（変えた所 `ArrangeEdit.fx` → `ArrangeBlock.fx`。ブロックのラベルのセレクトで選ぶ。なし = 曲の設定 `fxType`）。鳴らすときは発音時刻にあるブロックを `arrangementBlockAt("fx")`（`LoopArranger.ts`）で調べて種類を決めるので、再生中の変更もすぐ反映される。音源は種類ごとに1つで、曲の設定とアレンジで使う種類を読み込み時に作る（WAV書き出しでは鳴らしている途中に作れないため）。再生中に新しい種類を選んだときは鳴らす直前に作る。
  - 種類（`FX_DEFS`）：`riser` = ライザー（ノイズのバンドパス掃き上げ＋2オクターブ上がる重ねたノコギリ波、トレモロ・オートパンが加速）、`build` = ライザー＋インパクト、`impact` = インパクト（沈むブーム＋閉じていくノイズ）、`downlifter` = ダウンリフター、`reverse` = リバースシンバル、`chip` = チップSE（8bit。矩形波の駆け上がり＋「ピュン」）。
  - 各種類は `rise`（ループの終わりに向けて鳴り、ループの頭ちょうどで終わる。`riseLen` が `bars` なら1小節＝8小節以上の進行は2小節、`2n` なら最後の2拍）と `hit`（ループの頭）の片方または両方を持つ。音量の山は `setValueCurveAtTime` の曲線でかけ、終わりは短いフェードでクリックを防ぐ。
  - 広がり：ノイズは左右別々のノイズ（`stereoNoise`）で鳴らし、各種類の音は `space()`（左右で揺れのずれたコーラス → 左右に跳ねるディレイ）を通す。インパクトの低音のブームは中央のまま広げない。チップSE はコーラスなし（ディレイだけ）。後ろの響きは自前のリバーブを持たず、マスターのリバーブ送りとロングリバーブで付ける。
  - 音は lidless で出す（`GROW_FX`。コアの「FX …」のプリセット（ID は `fx_…`）を ID で探し、長さで変わる EG の時間などは、鳴らすたびに `GrowInstrument.setParamAtTime` で発音の少し前（`PARAM_LEAD`）に当てる。AudioParam の合図なので書き出しでもサンプル単位で合う）。lidless の準備ができていない・プリセットがない（wasm が古い）ときは `FX_DEFS`（Tone.js）で鳴らす。ライザー・ダウンリフターの音程は、ピッチ EG を直線のカーブにし、時間を長さいっぱいにして一定の速さで動かす（2オクターブ下から上がる／3オクターブ上から下がる）。
  - 種類を足すときは `FxType`（`AppState.ts`）・`FX_DEFS`・`GROW_FX`・`index.html` の `#c-fx-type` にそろえて足す。音色は再生開始時に反映される。

## 自動チェック

- 自動チェック（`QualityCheck.ts`）は画面には出さない（以前はアレンジャータブに欄があった。`analyzeSong()` は残してある）。数値は `songMetrics()`、合否は `QUALITY_RULES` で、`npm run quality`（`QualityBatch.ts`）も同じものを使う。項目を足すときは両方に出るよう `songMetrics` と `QUALITY_RULES`（合否があるなら `QualityBatch.ts` の `RULE_NAMES` と `quality-report.mjs` の `RULE_LABELS` も）に足す。項目：強拍（4/4 は1・3拍目、3/4 は1拍目。`isStrongUnit`）の響き（コードとぶつかる音＝構成音の半音上が `STRONG_CLASH_LIMIT`（20%）以下。コード構成音の割合は参考。2026-11-17 に「構成音が 75% 以上」から変えた：メロディはコード構成音を見ずに作るので構成音は平均 5 割ほどで、以前の基準は合格率 11% と良し悪しを分けられなかった。変えたあとは 85%。合否の名前は保存した結果と合わせるため `strongFit` のまま）、周回の最後の音が主音・構成音か、最大の跳躍（休符をはさまない音どうしで 9 半音以内）、サビの平均の高さが Aメロより高いか、セクション、アレンジの抜き差し（ON のパートが前の小節より減る所）、エンディング・フィルの回数、コード進行DB（全進行が実音にできるか・サビの相方があるか・長さが8小節のセクション（`LoopArranger.ts` の `SECTION_BARS`）を割り切れる 1・2・4・8 小節かその倍数で、コードが長さちょうどを埋めているか）、メロディのリズムDB（`melody_params.json` のリズム・フレーズ形式の書式）。
