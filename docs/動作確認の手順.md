# 最新の Toniq を試す手順

最新のコード（`origin/main`）で Toniq を起動して動作を確かめる手順です。

## 結論

- **動作を試すだけなら `npm run dev` で十分です。** .exe（インストール版）を作る必要はありません。
- .exe は、インストール版だけの動き（後述）を確かめたいときや、配布する前の最終確認のときに作ります。

## 1. 開発版で試す（ふだんはこちら）

```powershell
git fetch origin
git switch main
git pull                   # 最新の main にする（作業ブランチで試すときは origin/main より遅れていないか git status で確かめる）
npm install                # 依存パッケージが変わっていたときのため。変わっていなければすぐ終わる
npm run dev                # Vite と Electron が起動し、Toniq のウィンドウが最大化で開く
```

- Electron のウィンドウを閉じると Vite も止まります。
- ブラウザで `http://localhost:5173` を開いても画面は出ますが、書き出しはダウンロードになり、「出力フォルダを表示」ボタンなど Electron だけの機能は使えません。動作確認は Electron のウィンドウで行ってください。

### Electron が起動しないとき

VS Code のターミナルなどでは、環境変数 `ELECTRON_RUN_AS_NODE=1` が設定されていて Electron の起動に失敗することがあります。次のどちらかで起動してください。

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE; npm run dev
```

- または、Windows の普通の PowerShell やコマンドプロンプトから `npm run dev` を実行する

### 起動の前に壊れていないか確かめる（任意）

```powershell
npm run lint
npm run typecheck
npm test
```

## 2. インストール版（.exe）で試す

次のことを確かめたいときだけ作ります。

- 標準のメニューバーが出ないこと（インストール版だけの動き）
- 出力フォルダが Toniq.exe と同じ場所の `output/` になること（書き込めなければ「ドキュメント/Toniq/output」）
- 発表・提出・配布の前の最終確認

```powershell
npm run electron:build     # release/ にインストーラができる
```

`release/` にできたインストーラを実行してインストールし、Toniq を起動します。

### 注意

- 開発版とインストール版は保存領域のフォルダが同じです。**片方を開いている間は、もう片方を起動できません**（2つ目は1つ目のウィンドウを前に出して終わります）。
- ミュージックリスト（保存した曲）も両方で同じものを使います。

## 3. 確かめるとよい所

最近の修正（PR #90）に関わる所です。

- [ ] WAV / MP3 / MIDI の書き出しができる（書き出し中の「中断する」（Esc）で止まり、何も保存されない）
- [ ] 曲の終わりで自動で止まる（ウィンドウを最小化していても止まる）
- [ ] 二重起動しない（2つ目を開くと、1つ目のウィンドウが前に出るだけ）
- [ ] エンディングが最後まで鳴る

そのほか、基本の流れも一通り確かめます。

- [ ] シンプルモード：ジャンル・雰囲気を選んで「生成する」→ 再生 → 「♪ 保存」
- [ ] カスタムモード：設定タブで変更 → アレンジャー・ミキサー → 再生
- [ ] ピアノロール：メロディの入力・「自動生成」
- [ ] ミュージックリスト：保存した曲を開く・書き出したファイルを聴く
- [ ] 音楽クイズ・設定画面
