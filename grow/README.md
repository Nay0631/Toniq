# grow

Toniq の内部シンセサイザー。C++ で作り、同じ「コア」から2つの形で動く。

- **Toniq の中**：コアを WebAssembly にして AudioWorklet で鳴らす（メロディの音色「grow（テスト中）」）。再生・ミキサー・WAV / MP3 書き出しにそのまま入る。
- **単体**：[JUCE](https://juce.com/) で **Standalone（grow.exe）** と **VST3 プラグイン** にする。

JUCE は WebAssembly に公式対応していないので、音を作る部分（`core/`）は JUCE を使わない C++ で書き、JUCE は単体版の画面とホストとのやり取りだけに使う。

## ファイル

  GrowFx.h/.cpp             エフェクト（ドライブ・ディストーション（2倍オーバーサンプリング）・コンプレッサー・コーラス・ディレイ・リバーブ（8本の FDN）・マスター・DC カット・ソフトクリップ・リミッター）

## ビルド

### wasm 版（Toniq で鳴らす）

[Emscripten](https://emscripten.org/docs/getting_started/downloads.html) を入れ、`emsdk_env` で `emcc` に PATH を通してから、Toniq のフォルダで：

```bash
npm run grow:wasm   # → public/grow/grow.wasm
```

できた `public/grow/grow.wasm` は Git に入れる（Toniq を動かすだけの人が Emscripten を入れなくて済むように）。
コアを変えたらビルドし直す。wasm がないと、Toniq では grow を選んでもジャンルの標準の音色で鳴る。

### 単体版（JUCE）

Visual Studio 2022（「C++ によるデスクトップ開発」）・CMake 3.22 以上・Git が必要。

```bash
cd grow
cmake -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
```

最初の構成で JUCE 8.0.4 を GitHub から取得する（手元の JUCE は `-DGROW_JUCE_DIR=C:/path/to/JUCE`）。
できあがるのは `build/grow_artefacts/Release/Standalone/grow.exe` と `build/grow_artefacts/Release/VST3/grow.vst3`。
JUCE のライセンス（AGPLv3 か商用ライセンス）に注意する。

## 音の流れ

```
OSC 1・OSC 2（ユニゾンで最大7枚重ね、左右に広げる。FM・リング・ハードシンク・パルス幅）＋サブ（1オクターブ下のサイン）＋ノイズ（左右別々）
  → フィルター（ローパス 12 / 24・ハイパス・バンドパス。フィルター EG・LFO・キー追従でカットオフを動かす）
  → アンプ（ADSR・ベロシティ・LFO）
  → 16音を足す → ドライブ → ディストーション → コンプレッサー → コーラス → ディレイ（テンポ同期・左右に跳ねる）→ リバーブ（FDN）→ マスター → DC カット → ソフトクリップ → リミッター
```

- ユニゾン：デチューンは外側ほど大きく（位置の 1.5 乗）、真ん中の音（偶数枚なら内側の2枚）は真ん中に置いてずらさない。外側の音の大きさはデチューンが小さいほど控えめで、全体のパワーは枚数・デチューンによらずそろえる。
- EG は指数カーブ（アタックは上に膨らみ、ディケイ・リリースは dB が一定の速さで下がる）。各段の時間ちょうどで次の段へ進む。サスティンが 0 なら、ディケイで 0 に届いた所で終わる（鍵盤を押したままでもボイスが空く。ドラムは消音の合図なしで鳴らし切る）。
- ボイスのモード：ポリ（16音）／モノ／レガート（押したまま次を押すと EG を掛け直さずにつなぐ）。グライドは前に弾いた音から滑らせる。フィルターのドライブ（0〜1）は入力を持ち上げて積分器を飽和させ、レゾナンスを丸く太くする（0 なら線形のまま）。フィルターのベロシティ（0〜1）は弱く弾くほどカットオフを下げる（最大 2 オクターブ）。ドリフト（0〜1）は音ごとに高さ（最大 ±7 セント）・カットオフ（最大 ±2 半音）を少しずらし、高さをゆっくり揺らす（最大 ±4 セント）アナログらしいずれ。「OSC 2 を通さない」をオンにすると OSC 2 はフィルターを通らずフィルターのあとに足す（ハイパスで低域を削っても、OSC 2 の素の音で支えられる）。
- OSC 変調：矩形波のパルス幅（OSC ごと。幅を変えても 0 を中心にする）、FM（OSC 2 → OSC 1 の位相変調。最大 ±1.5 周期）、リング（OSC 1 × OSC 2）、ハードシンク（OSC 2 の位相を OSC 1 の周期ごとに頭に戻す）。FM・リングの元は OSC 2 の高さ・波形で鳴る1本の波で、OSC 2 の音量・ユニゾンによらない（OSC 2 の音量を 0 にして変調だけに使える）。
- LFO：波形（サイン・三角・ノコギリ・矩形・ランダム）、速さは Hz かテンポ同期。行き先は高さ・フィルター・音量・パルス幅（PWM）に別々の量で送る。フェードイン（秒）で発音から深さを 0 から上げられる（伸ばすと深くなるビブラート）。
- LFO 2・EG 2：行き先を持たず、モジュレーションの割り当てで使う。LFO 2 は LFO と同じ設定（波形・速さ・テンポ同期・リトリガー・フェードイン）、EG 2 は ADSR（初期値はサスティン 0）。
- モジュレーション：4つの割り当て（元 × 量（−1〜1）→ 行き先）。元は ベロシティ・EG 2・LFO 1・LFO 2・フィルター EG・キー（C4 = 0、5オクターブで ±1）・ランダム（音ごと）。行き先と量 1 の大きさは 高さ・OSC 2 の高さ（±24 半音）、カットオフ（±48 半音）、パルス幅（±0.45）、音量（1 + 量 × 元 を掛ける）、FM・リング（±1）、LFO 1 の速さ（±4 オクターブ＝量 1 で 16 倍。前のサンプルの値で当て、1周 4 サンプルより速くしない。EG で加速するトレモロ・効果音に使う）。
- ピッチ EG：発音の瞬間に「量」だけずらし、「時間」（最大 10 秒）で 0 に戻す。カーブは 指数（はじめ速く戻る）か 直線（半音で一定の速さ。Hz では指数的に動くので、ライザーなどに合う）。
- エフェクト：
  - ドライブは tanh の歪みを2倍の速さ（31 タップのハーフバンド FIR で上げ下げ）でかけ、倍音の折り返しを抑える。0 の間は何もしない（上げると約 7.5 サンプル遅れる）。
  - ディストーションは種類（チューブ＝正負で丸め方の違う tanh で偶数倍音が出る／ハード＝±1 で切る／フォールド＝サインのウェーブフォルダー／ビット＝間引き＋段数を減らすビットクラッシャー。歪み 0 で 16 ビット・間引きなし、1 で 4 ビット・31 サンプルごと（2倍の速さで数える））・歪み（チューブ・ハードは入口を最大 +30dB、フォールドは +24dB 持ち上げる）・トーン（1次のローパス2段）・量。ドライブと同じく2倍の速さで歪ませ、歪ませた音は直流を切ってから、元の音と平均の大きさ（50ms・左右まとめたパワー）をそろえて混ぜる（歪みを強くしても音量はほぼ変わらず音色だけ変わる。量が 1 未満でも、混ぜるのは2倍の速さの中なので元の音と FIR の遅れがずれない）。量が 0 で落ち着いている間は何もしない。
  - コンプレッサーは左右の大きい方のピーク（dB）で下げ幅を決める（ソフトニー 6dB。左右に同じだけかける）。スレッショルド（−48〜0dB）・レシオ（1〜20）・アタック・リリース・メイクアップ（0〜24dB）・量（元の音と混ぜる。1 未満ならパラレルコンプ）。スレッショルドはマスターの手前の大きさで見る（プリセットごとに大きさが違うので、音を見ながら決める）。量が 0 の間は何もしない。
  - コーラス・ディレイ・リバーブは、量が 0 で落ち着いている間は計算しない（Toniq は1つの wasm で多くの音色を鳴らすので、使わないエフェクトの負担を減らす）。量を上げ直すときは古い響きが出ないようバッファを空にしてから、量を 0 から滑らかに上げる。
  - コーラスは揺れるディレイを左右3本ずつ（揺れの位相を 120° ずつ、右は左から 60° ずらす）。
  - ディレイのくり返しは、ローパス（4.5kHz）・ハイパス（120Hz）・弱い飽和を通す（テープ風に、くり返すほど丸く細くなる）。
  - リバーブは FDN：入口をオールパス4段で散らし、8本のディレイ（互いに割り切れない長さ）を Householder 行列で混ぜる。くり返しごとにローパス（6.5kHz）をかけ、2本の長さをゆっくり揺らして金属的な鳴きを抑える。「広さ」0〜1 は響きが 60dB 下がるまでの時間 0.5〜8 秒（0.5 で 2 秒）。響きの大きさ（`reverbWetGain`）は以前の Freeverb と同じくらいに合わせてある。
- テンポ：単体版はホストの BPM（Standalone は 120）、Toniq では曲の BPM。

## Toniq とのつなぎ方（wasm 版）

- `src/engine/Grow.ts`：wasm を読み込み（`public/grow/grow.wasm`）、画面のスレッドにも1つインスタンスを作って、パラメーターの表・プリセット・値の表示に使う。AudioWorklet はオーディオコンテキストごとに登録する（再生用と書き出し用）。
- `src/engine/growWorklet.js`：AudioWorklet。wasm をインスタンス化して 128 サンプルずつ描く。1つのノードで最大16の音色（スロット）を鳴らす（マルチティンバー。スロットごとに出力1つと合図の AudioParam `on{n}` / `off{n}` / `pidx{n}` / `pval{n}`）。
- マルチティンバー：wasm（`grow_wasm.cpp`）はスロットごとにエンジンを持つ（`grow_open` / `grow_close` / `grow_*_slot`。最大32。スロット番号を取らない関数はスロット 0）。メモリは開いたエンジンの分だけ伸びる（`ALLOW_MEMORY_GROWTH`）ので、ワークレットは描くたびに出力の参照を確かめ直す。Toniq（`Grow.ts`）は同じタスクで作った `GrowInstrument` をマイクロタスクでまとめて1つのノードにする（再生の開始・書き出しでは全パートが1つのノード・1つの wasm）。スロットの最初の値は `processorOptions` で渡し、ノードができる前の発音・パラメーターはためておいて当てる。
- 音符は AudioParam（`on` / `off`）の1サンプルだけの合図で渡す（`on` = ノート番号 + 1 + 強さ × 0.5、`off` = ノート番号 + 1）。port のメッセージは書き出しのときに届くのが遅れることがあるので、音符には使わない。時刻を決めて当てるパラメーター（`GrowInstrument.setParamAtTime(ID, 値, 時刻)`）も、AudioParam（`pidx` = 番号 + 1 の1サンプルの合図、`pval` = 値）で渡す（同じサンプルでは パラメーター → 発音・消音 の順に当てる。同じ時刻に複数当てると2サンプルずつずれる）。すぐ当てればよいパラメーター（音作りのパネル）・BPM は port で送る。
- 音の終わりの合図は 2ms 遅らせ、すき間なく続く音が重なるようにする（レガートでつながる）。同じ高さの音が続くときは、ワークレットが前の音の終わりを無視する。
- Toniq ではメロディ・コード（音色が grow のとき）とベース・パッド・アルペジオ・シグネチャー・FX / SE（いつも）を grow で鳴らす。和音は同じサンプルに重なる合図を2サンプルずつずらして渡す。
- 曲に保存するのはパートごとのプリセットの ID（`GrowPresets.cpp` の `id`。wasm の `grow_preset_id`）と変えた値（ID → 値。null = プリセットのまま）：メロディ `AppState.growPreset` / `growParams`、コード `growChordPreset` / `growChordParams`、ベース・パッド・アルペジオ・シグネチャー `growSounds`（プリセットの null = ジャンルの標準）。
- FX / SE（`src/engine/FxPlayer.ts` の `GROW_FX`）は「FX …」のプリセット（ID は `fx_…`）を探して鳴らし、テンポで変わる EG の時間などをその場で上書きする。プリセットがなければ Tone.js の音で鳴る。
- ドラム（ドラムの音源が「grow」のとき。`src/engine/SynthFactory.ts` の `GROW_DRUMS`）は「ドラム …」のプリセット（ID は `drum_…`：キック・スネア・ハイハット（クローズド／オープン）・クラップ・リム）を1つの打楽器につき1台鳴らす。ジャンルのキットの値（高さ・長さ・帯域など）はプリセットの値を上書きして当てる。どれもサスティン 0 なので発音の合図だけ送り、オープンハイハットを止めるときだけ消音の合図を送る。キックはサインをピッチ EG で沈め、クリックはフィルター EG で頭だけ通すノイズ。スネアは胴鳴り（三角波・OSC 2 を通さない）＋バンドパスのノイズ。ハイハットは高い矩形波どうしのリング・FM にノイズを重ねたハイパス。
- パーカッション（Toniq のパート「パーカッション」。ドラムの音源が「grow」のとき。`src/engine/SynthFactory.ts` の `GROW_PERC`）は「パーカッション …」のプリセット（ID は `drum_shaker` / `drum_tambourine` / `drum_conga` / `drum_ride`）。ドラムと同じく1台で1つの打楽器・サスティン 0 で、`--suggest` では役割 `drum`（ピークをそろえる。ノイズだけのシェイカーは `DRUM_PEAKS` で −7.5dB）。コンガは高い・低いを音の高さ（A3 / E3）で鳴らし分ける。
- パッド・アルペジオ・シグネチャーのジャンルの標準は、`src/engine/Grow.ts` の `GROW_STANDARD` がプリセットを ID で探す（候補を前から順に。今の wasm にない ID は飛ばす）。

## 確認・測定（`grow/tools/render.mjs`。`npm run grow:render`）

wasm を Node で直接鳴らして、全プリセット（`--preset id,…` で絞れる）を測る。ブラウザも Toniq も要らない。

- プリセットの使われ方（`ROLES`：リード・和音・ベース・速い刻み・FX・ノイズ）に合わせたフレーズを 48kHz・120 BPM で鳴らし、ピーク・聞こえる大きさ・直流・余韻（最後の音から5秒後に消えているか）・NaN を出す。壊れた音があれば終了コード 1。
- 聞こえる大きさはモーメンタリーラウドネスの最大（ITU-R BS.1770 の K 特性・400ms の窓。LUFS）。
- `--wav`：`output/grow/<ID>.wav` に書き出す（Git 管理外）。
- `--suggest`：聞こえる大きさを目標にそろえる `master` の値を出す。目標は −18 LUFS。FX は組み合わせて鳴らす音どうしの差を Tone.js 版と同じに残す（`TARGETS`：ライザーの音程 −24、インパクトのノイズ −26、ダウンリフターの音程 −19）。ヒス・プチプチはわざと小さいのでそろえない（`FIXED`）。ドラム（役割 `drum`。8分音符で8回打つ）は聞こえる大きさではなく強さ 1 のピークを −6dB（`DRUM_PEAK`。出力段のソフトクリップの手前）にそろえる（ノイズが主のスネア・クラップは `DRUM_PEAKS` で目標を下げている）。Toniq はシンセのドラムとの差を `GROW_TRIM_DB` で合わせているので、ドラムの master を変えたらそちらも測り直す。提案が `master` の上限（+6dB）を超えるときは、OSC・ノイズの量を上げてから測り直す。
- `--set ID=値,…`：プリセットの値を上書きして鳴らす（例 `--preset saw_bass --set dist_type=2,dist_mix=0.5 --wav`。エフェクトの試聴・プリセットの調整に使う。`master` を上書きしたら提案もその値から求める）。
- `--analyze <WAV …>`：書き出した曲などの WAV のピーク・統合ラウドネス（ゲート付き）・聞こえる大きさの最大を測る。
- プリセットの `master` は `--suggest` の値にしてある。音色を変えたら測り直して書き換える（初期化のプリセットは対象外）。

## 決まりごと

- パラメーターを足すときは `core/GrowParams.h` の `Param` と `GrowParams`、`core/GrowParams.cpp` の `table`（並びは `Param` と同じ）と `makeParams()` に足す。単体版の画面・Toniq の暫定のパネルは表から作るので、新しいモジュール名を足したときだけ `Source/PluginEditor.cpp` の `layoutRows` にも足す。ID は一度出したら変えない（保存した状態・曲・ホストのオートメーションが読めなくなる）。
- 音作りは [sleepfreaks のシンセレシピ](https://sleepfreaks-dtm.com/category/synth-recipe/) を参考にしている（ハードパッド・ゲートパッド・ファットベース・パルスベース・ワブルベース・トランスリード・加速SE、ライザーの加速するトレモロ など）。
- プリセットには変えない ID（ASCII）を付ける。Toniq は曲に ID を保存し、ID で探す（名前・並びを変えても曲の音は変わらない）。ID は一度出したら変えず、消すときは Toniq の `GROW_STANDARD` などの候補から外す。並びは JUCE 版のプログラム番号になるので、足すときは後ろに足す。番号で保存していた頃の曲は、Toniq の `LEGACY_PRESET_IDS`（`src/engine/Grow.ts`。その時点の並び）で ID に読み替えるので、この表は変えない。
- つまみの値は段差で当てない（ジッパーノイズになる）。音量・カットオフ・レゾナンス・ユニゾン・エフェクトの量などは `Smoother`（`GrowDsp.h`。時定数 `smoothSeconds`）か、ブロックの中で直線につなぐ形で滑らかに変える。新しく鳴らす音は今の値から始める（`snapNext`）。連続的なパラメーターを足したら同じようにする。
- 鳴っている音をいきなり止めない（クリックになる）。差し替えは `Voice::steal`（約 4ms フェードしてから鳴らす）、まとめて止めるときは `Voice::fadeOut`。すぐ止める `allNotesOff` は再生の停止・初期化だけに使う。
- wasm には FTZ / DAZ がないので、フィードバック・減衰で 0 に近づく状態（フィルター・コム・オールパス・ディレイ・EG など）は `flushDenormal` を通す（極小の値で計算が10倍ほど遅くなる）。
- コアはオーディオスレッドで確保しない（バッファは `prepare` で確保する）。例外・RTTI は使わない（wasm は `-fno-exceptions -fno-rtti`）。
- 日本語の文字列はコアでは UTF-8 の `const char*` のまま持ち、JUCE では `jp("…")` を通す（`juce::String (const char*)` は ASCII 前提）。ソースは UTF-8 で保存する（MSVC は `/utf-8`）。
- wasm に関数を足すときは `wasm/grow_wasm.cpp`（`GROW_EXPORT`）と `wasm/build.mjs` の `exported` の両方に足す。
